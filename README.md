# Black Hold

Black Hold es una aplicación web académica creada con HTML, CSS y JavaScript.

Su objetivo es ayudar a organizar:

- Materias
- Tareas
- Exámenes
- Sesiones de estudio
- Repasos
- Hábitos
- Metas académicas
- Estadísticas
- Preparación PAES
- Preparación SAT
- Preuniversitario

## Funciones incluidas

La aplicación incluye:

- Panel principal
- Fecha actual
- Frases motivacionales
- Barra de progreso diaria
- Tareas pendientes
- Prioridades
- Materias personalizadas
- Metas semanales
- Cronómetro de estudio
- Pomodoro
- Historial de sesiones
- Repasos programados
- Exámenes
- Porcentaje de preparación
- Hábitos diarios
- Estadísticas
- Rachas de estudio
- Modo oscuro
- Exportación de datos
- Importación de datos
- Funcionamiento sin conexión
- Instalación como aplicación web
